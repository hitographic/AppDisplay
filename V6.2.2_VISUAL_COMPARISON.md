## 💡 Key Insight

**PENTING:** Validator perlu tahu **KAPAN EDITOR EDIT**, bukan kapan validator itu validasi!

Validator validasi untuk memastikan data yang **EDITOR BUAT/EDIT SUDAH BENAR**.

Jadi popup harus tampilkan:
- ✅ **updatedAt** = kapan editor terakhir edit
- ✅ **updatedBy** = siapa editor yang edit

Bukan:
- ❌ validatedAt = kapan validator validasi (baru/sekarang saja)
- ❌ validatedBy = siapa validator (bukan penting untuk view ini)
